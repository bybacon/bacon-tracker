Title: Ship a demo tracker for trials and screenshots

**Description:**
Newcomers had no quick way to see a realistic board, and the README had no
reliable source for its screenshot. A small demo tracker in the repository
now boots with one command. Its stories span every stage and type and show
sizes, assignees, a blocker and subtasks, so the board's features are all
visible. The README's board screenshot is taken from it. The demo lives only
in the repository, not in the gem.
