Title: Record the decisions that were never written down

**Description:**
The decision log held only three records, all about packaging. The key
product and design decisions lived in code or in people's heads. Recording
them now means Ingo can still find out months later why the tracker works
the way it does. The new records cover the workflow verbs, error handling,
stage directories as the source of truth, subtask addressing, CLI naming,
the field grammar, files instead of a database, sequential ids and the two
setup modes. An index of the decision log was added as well.
