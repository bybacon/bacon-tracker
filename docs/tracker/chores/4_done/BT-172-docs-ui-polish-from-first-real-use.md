Title: Docs UI polish from first real use

**Description:**
Ingo's first real session on the docs and decisions pages turned up five rough
edges. The pages lacked the board's header and theme toggle. Rendered
markdown had no styling, so tables looked broken and list markers were
clipped. The file column was too narrow and cut off names. The reveal icon
differed from the board's. The decision detail view showed its title twice.
Fixing these makes the docs pages feel like part of the same app as the board.
