Title: Add a testing overview doc

**Description:**
Contributors had no single place that explained what is tested, how, and
where new tests belong, though the pull request checklist asked for one. A
testing overview now explains how to run the Ruby and JavaScript tests and
the testing approach. It maps each test file to what it covers and
describes what CI runs. It is linked from the README and the contributing
guide, and it ships with the gem.
